#Space Voyage

##This was just a game that I made and was messing around with to learn the Phaser framework for creating games.  It was never finished due to needing to prioritize other things in life, but I imagine I'll get back to it later since it has been an idea in my head for a very long time.


Setup:

- Download Visual Studio Code (https://code.visualstudio.com/)
- Download Project and extract.
- "File" menu > "Open Folder" > open project folder.
-  npm run dev

 Controls:

 - Left/Right keys to move left/right.
 - Up key to jump.
 - Space button to interact with objects (rectors, terminals, cryo tubes, etc).
